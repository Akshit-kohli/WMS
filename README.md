# WMS
WMS is a Weight bridge Management System. It is designed with a goal of it as an industrial level project.

Working:-
1. Vehicle arrives
2. Operator enters: Customer name, phone, vehicle number,vehicle type, material type
3. Vehicle goes on scale → GROSS WEIGHT captured
4. Vehicle offloads material
5. Vehicle goes on scale again → TARE WEIGHT captured
6. NET WEIGHT = Gross - Tare
7. CHARGES = Net Weight × Rate per ton (per material type)
8. Receipt printed
9. Data saved to DB
